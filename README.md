## Descripción del proyecto y uso del mismo:

NóminaLibre es una aplicación de escritorio
que permite gestionar trabajadores y realizar liquidaciones
mensuales de nómina.

El sistema maneja tres tipos de trabajadores: Empleados de planta,
contratistas y empleados por horas. Cada tipo de trabajador tiene
una forma diferente de calcular su pago y, cuando se necesita,
su bonificación por antigüedad.

La aplicación utiliza una interfaz gráfica desarrollada con Java
Swing y una base de datos SQLite para almacenar la información.

Tiene como funcionalidad:

- Registrar trabajadores.
- Consultar los trabajadores registrados.
- Editar la información de los trabajadores.
- Eliminar trabajadores con confirmación.
- Calcular pagos según el tipo de trabajador.
- Calcular bonificaciones por antigüedad.
- Realizar liquidaciones mensuales.
- Consultar el historial de liquidaciones.
- Consultar el total de nómina mensual por tipo de trabajador.
- Consultar los trabajadores sin pago en un periodo.
- Activar y desactivar las alertas de pagos superiores a $8.000.000.
- Mostrar el total de las liquidaciones realizadas durante la sesión.
- Validar los datos mediante excepciones personalizadas.
